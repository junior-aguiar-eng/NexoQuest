Diretrizes Fixas e Guardrails (ADR-001 a ADR-010)
ADR-001 — Adaptar QuizHP

Reaproveita MCP transport e bridge sem refatoração big-bang.

ADR-002 — Não Monorepo

Mantém estrutura simples em raiz com isolamento modular estrito.

ADR-003 — Core Desacoplado

Nenhum import de OpenAI/MCP dentro de domain, library ou quiz.

ADR-004 — Sem API no Backend

O LLM do host gera questões; servidor apenas valida e corrige.

ADR-005 — Markdown Canônico

Arquivos .md são a fonte da verdade; SQLite é apenas cache e FTS.

ADR-006 — Gabarito Protegido

QuestionPublic nunca tem gabarito; chave trafega em token AES-GCM.

ADR-007 — Separação de Estados

Estado transitório de UI separado de widgetState e SessionRepository.

ADR-008 — Stateless Pro

Fluxo do ChatGPT funciona sem exigir permissões de escrita (write/modify).

ADR-009 — Validações Determinísticas

Regras de bloco (3 hard, 1 med, 1 easy) e rotação de letras no código.

ADR-010 — Git Privado

origin = privado; upstream = público QuizHP. Push restrito a origin.

Matriz de Validação & Cobertura

A pirâmide de testes do NexoQuiz prioriza testes unitários determinísticos rápidos (Zod, validadores de bloco e crypto de gabarito), seguidos de testes de integração das MCP tools e testes visuais do QuestionPlayer.


  • TC-DOM: Schemas estritos para 5 alternativas (A-E), UMT, QuizPlan e QuestionPublic.
  • TC-SEC: Envelope cifrado com AES-GCM impedindo visualização prévia de gabarito.
  • TC-LIB: Parser de frontmatter, índice FTS5 e bloqueio de path traversal.
  • TC-UI: QuestionPlayer acessível, atalhos de teclado e accordions recolhidos.
